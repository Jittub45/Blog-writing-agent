# Blog Writing Agent

An AI-powered blog writing agent built with Python, featuring research capabilities, improved prompting, and image generation.

## Project Structure

| File | Description |
|------|-------------|
| `1_bwa_basic.ipynb` | Basic blog writing agent |
| `2_bwa_improved_prompting.ipynb` | Agent with improved prompting techniques |
| `3_bwa_research.ipynb` | Agent with web research capabilities |
| `4_bwa_research_fine_tuned.ipynb` | Fine-tuned research agent |
| `5_bwa_image.ipynb` | Agent with image generation support |
| `bwa_backend.py` | Backend API server |
| `bwa_frontend.py` | Frontend application |
| `tavily_test.ipynb` | Tavily search API testing notebook |

## Getting Started

### Prerequisites

- Python 3.9+
- Jupyter Notebook

### Installation

```bash
pip install -r requirements.txt
```

### Usage

**Run the backend:**
```bash
python bwa_backend.py
```

**Run the frontend:**
```bash
python bwa_frontend.py
```

Or explore the Jupyter notebooks for step-by-step development and experimentation.
